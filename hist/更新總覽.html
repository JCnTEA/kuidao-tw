目前狀態

修正

Google 行程改成 iCal 網址訂閱

Google 已停止 CalDAV 的密碼登入，只接受 OAuth 2.0，所以「Gmail + 應用程式密碼」一定回 401。新增「iCal」平台：到 Google 日曆 → 設定 → 整合行事曆複製「秘密 iCal 網址」，貼上就能只讀同步，不需帳號密碼。原本的 Google 卡保留但會提示改走 iCal。

簡化

天氣來源只剩 Open-Meteo

和風天氣整套拿掉：不再出現雙卡選擇、API Host／Key 表單、和風城市與配置教程。設定頁只留一張 Open-Meteo 卡，固定為預設；舊版存過和風的人啟動後也會自動回到 Open-Meteo，不需要 Key。

調整

吉祥物動畫包回來：可開啟資料夾、直接匯入、重新載入

整併上游後，「外觀 → 島體顯示」只剩開關，原本的吉祥物形象說明、動畫包資料夾與重新載入都不見了。現在補回並加上「匯入動畫包…」：選一個內含 pack.json 的資料夾，會複製到 mascot-packs，重新載入後套用；沒有動畫包時照用內建石虎。

調整

電量裝置頁改用無線設備的詳情版式

只有一台裝置時，不再是一個小環擺在中間，改成跟「無線設備」一樣：左邊大環、右邊名稱與大百分比、充電狀態、讀取來源與時間，以及常駐顯示開關。

整理

設定頁不再出現 LINE 開發者帳號與本機通知來源

「訊息提醒」頁原本混入 LINE Login 的 Channel ID／Secret／Callback URL，以及給插件接入端用的「本機通知來源」授權表單，這些不是一般使用者要調的。已整段移除；社群與聊天軟體的通知設定保留。

修正

社群通知收不到時可以直接重新連線

「社群與聊天軟體」卡新增「重新連線」：不必先斷開再連線，按一次就讓 Windows 重新授權並重建通知監聽。LINE、Instagram、Threads、Messenger、Facebook 的未讀仍會顯示在島上。

調整

更新內容改為「開發版→正式版」累積總覽

正式版的更新說明不再只寫單一修正，改把開發版時期（上游整併後）到現在正式版的內容一次列清楚：上游整併、插件系統、信箱與行程合併、更新內容卡、漸層亮度、瀏覽器音樂、感謝牆與支持人數移除、贊助頁保留、檢查更新一鍵下載等。按一次「檢查更新」就會重新抓取這份說明。

修正

檢查更新：自動開更新視窗並直接下載

之前按下「檢查更新」只會查版本，還要再按「發現新版本」→「立即更新」才會動作。現在按一次就一條龍：查到有新版就自動跳出更新視窗（顯示版本與更新內容）並立刻開始下載，下載完成自動重啟，不必再按任何確認。

修正

贊助頁回到側欄（正式版也有）

之前為了讓正式版乾淨，把整頁贊助從正式版側欄藏起來，結果正式版根本找不到。現在正式版與開發版都保留「贊助」頁（說明、咖啡卡、街口支付與支付寶收款碼）；「關於」頁仍然不會出現任何贊助內容。

發布

正式版上線

以目前開發版內容打包正式版：安裝檔與免安裝包都已發布，官網下載按鈕指向固定資產；正式版只走正式更新通道，贊助頁不顯示。版本線就從這一版重新起算。

修正

瀏覽器音樂追蹤：Chrome／Edge 播放歌曲不再「暫無音樂」

兩個原因一起修：① 瀏覽器常把 YouTube 歌曲回報成「影片」，以前會被影片過濾直接丟掉，現在只要標題像歌名就照音樂上島；② 有瀏覽器在出聲、但視窗標題抓不到可辨識歌名時（Edge 常見），以前整輪放棄，現在仍會交給「聽歌辨識」聽聲音認歌並補回歌名。另外挑視窗時優先選 YouTube／KKBOX／Spotify 這類播放頁，避免把信箱或文件的標題當成歌。

調整

贊助頁不再顯示支持人數與最近支持

贊助頁維持說明、咖啡卡、街口支付與支付寶收款碼；下方「已有 115 位朋友請鬼島喝過咖啡」與最近支持頭像整段移除，畫面乾淨很多。

新增

外觀：懸浮漸層可調亮度（台灣版）

選到懸浮漸層任一皮膚時，「島體外觀」多一列「調整漸層亮度」開關；關閉時維持原始亮度 100%，打開後可用 60–100% 拉桿調深淺，另附「恢復預設」（80%）。只影響漸層底色，文字與圖示亮度不變，設定會記住。

調整

感謝牆整頁移除；「關於」頁也不再出現任何贊助內容

贊助只留在側欄的贊助頁：說明、街口支付與支付寶收款碼照舊，但原本的感謝牆（一整面支持者頭像）與「查看感謝牆」入口已整個拿掉，最近支持那一排頭像也不再顯示。另一方面，「關於」頁回到單純的版本、檢查更新、更新內容、開資料夾與診斷，贊助卡片與支持者數字都不再出現在關於頁。

修正

插件頁全繁體：上游集市的插件名稱、作者與說明都轉成繁體再顯示

插件集市是直接讀上游作者的目錄，內容本來是簡體，所以卡片標題與說明看起來仍是簡體。現在程式在讀取目錄與插件清單時，只把顯示用的名稱、作者、說明與設定欄位標籤轉成繁體（台灣字形），其餘 id、版本、檔案、雜湊與下載網址完全不動，上游新增或更新的插件一樣照收，不會漏掉任何一款。

修正

關於頁的「更新內容」框回來了：檢查更新後留下最新一筆說明

併入上游版本時，「關於」頁的更新內容區塊被新的更新流程蓋掉，變成只有版本號與按鈕。現在補回一個更新內容卡片：按「檢查更新」查到版本後，會把那一版的說明存成一筆並顯示在這裡，只保留最新一筆、不累積舊資料；開發版同樣會寫入，不再只有正式版才有。

修正

插件集市在開發版一直沒出現：建置沒開插件功能，現在補上

設定側欄最底下找不到「插件」，不是合併時漏掉，而是開發版建置指令少帶了插件功能開關，整段插件介面根本沒被編進執行檔。現在建置已照上游正式版的參數一起開啟插件與材質功能，插件集市、已安裝清單、各插件設定頁與狀態小卡都會出現在「設置 → 插件」，首批八款可直接瀏覽、安裝與更新。

設定

設定側欄重新排好：贊助自己一頁，插件集市固定壓在最底下

插件集市與贊助頁先前撞用同一個分頁編號，點「贊助」會跳出插件頁，贊助內容反而看不到。現在三頁各自獨立：贊助排在「關於」上方，點進去是「贊助鬼島」說明與支援作者卡片（街口支付與支付寶收款碼，卡片展開才解碼、收起即釋放），只在開發版出現；插件移到側欄最底下最後一行，集市與已安裝清單、各插件設定頁照上游原樣；「關於」維持原本版本與更新內容。側欄分頁名也照台灣用語改為「訊息提醒」，贊助頁補上專屬圖示。

調整

信箱與行程合成一頁：同一組 Google 帳號，一起抓信件也一起抓行程

以前信箱和行程是兩個獨立分頁，行程還要另外輸入一次帳號密碼。現在合成「信箱與行程」一頁，頁面上方一顆小按鈕在兩者之間切換，分頁列少一格、少一份設定。更關鍵的是帳號共用：新增 Gmail 信箱時，同一組應用程式密碼會自動補進行程憑據，信件與行程同時開始同步，不必再另外登入；既有使用者下次啟動也會自動接上，原本手動設過的行程帳號不會被覆蓋。行程本身仍只讀，憑據一樣只存在系統憑據管理器。

更新

「檢查更新」按下就自己換版：自動檢查、自動下載、自動重新開啟

以前手動按下「檢查更新」只會跳出「發現新版本」，還要自己再點一次下載、跑完安裝程式、手動開回來；開發版更是常常顯示「當前已是最新版本」，其實本機還停在舊開發版。現在按鈕按下就是一條龍：先問線上最新開發版，比對本機版本，有新版本就自動下載整包（程式與素材一起換），換完自動重新開啟鬼島；沒有新版本就直接開回原本的程式，不會卡在舊版。開發版每次建置都會另外發布一個帶版本的開發版標籤，啟動器與程式按鈕都對得到最新那一包。

新功能

跟上上游最新內容：插件集市、系統效能頁、無線設備頁一起進開發版

這次把上游最新一版整份併進鬼島開發版，重複的地方一律以上游為準，原本台灣版自己做過的功能再逐一接回來。新增三塊：一是插件集市，首批八款插件可以直接在程式裡瀏覽、安裝與更新，插件各自有設定頁與狀態小卡，選單分組與權限提示一并補齊；二是系統效能頁，把 CPU、記憶體、磁碟與網路即時曲線畫在同一頁，可切換要看哪幾項、顯示成條狀或折線；三是無線設備頁，藍牙耳機、滑鼠、鍵盤、手機等裝置集中在一頁，顯示連線狀態與電量，可釘選常駐在島上。

體驗

拖動、停靠與遮蔽都更貼近桌面習慣：可以停在螢幕底部，跨屏拖動不卡住，截圖錄屏時自動讓位

島體除了貼頂，現在也能停靠螢幕底部，展開方向與陰影跟著換邊，多螢幕之間可以一路拖過去，不會卡在螢幕邊界或跳到另一塊桌面；截圖與錄屏時會自動隱藏，畫面乾淨不被島體擋住，結束後自己回來。置物架改成保持展開，切到其他頁再切回來不會重新收合；相容渲染模式也調順了，弱顯卡或遠端桌面下開合與翻頁不再頓一下。

順暢度

「很卡」先做成看得到的數字：檔案選擇視窗改背景開啟，慢幀自動拆段

實際跑起來抓到的診斷顯示：閒置時介面幾乎固定停在每秒 58 幀，代表畫面一直有人在要求重畫，而不是真的在播放動畫；慢幀紀錄裡最長的一筆是置物架頁 23 秒，其後接著 10 秒、8.5 秒、6 秒，共通點都是「開著新增檔案的系統視窗」。原因是系統開檔對話框是模態的，先前直接跑在主執行緒上，對話框沒關之前整個島都停住，看起來就是嚴重卡頓。現在開檔一律丟到背景執行緒，並在該執行緒自己初始化 COM，選完再把結果交回介面；等待期間點擊、動畫、時鐘與其他頁面照常運作，跳出「先前開啟的檔案選擇視窗還沒關閉」也不會再開第二個。另外慢幀紀錄多了「前置／繪製／視窗與郵件／設定」四段耗時，以及每十秒一筆的「節奏」紀錄（重繪間隔與原因，例如開合翻頁、尺寸收斂、提示彈出、播放或流體動畫），下次回報卡頓時可以直接看出是哪一段、哪個元件在空轉。

行事曆

Google 連線 401 先看應用程式密碼是不是 16 碼

Google 的應用程式密碼固定 16 碼，複製時少抓兩碼、或多帶一個字，伺服器只會回一個沒有線索的 401，先前只能反覆重填。現在按下驗證前會先檢查長度：Google 與 iCloud 的應用程式密碼不是 16 碼就直接擋下來，提示寫出目前打了幾碼、正確是 16 碼，並提醒要先把該帳號的兩步驟驗證打開、再到「應用程式密碼」產生一組新的；多打了字也會另外提示。真的送出後才失敗的 401 維持原本的說明，不會把「格式不對」誤報成「帳號或密碼錯誤」。

設定

贊助頁的綠界收款碼換成街口支付

「請喝咖啡」展開後的雙欄收款碼左邊原本是綠界贊助碼，現在整張換成街口支付的收款碼：標題改用街口紅、寫「街口支付」，下方提示改成「用街口支付掃一掃」，掃進去直接是轉帳頁；右邊支付寶維持原樣，兩張都只留方形掃碼區、比例與大小一致。舊的綠界圖檔從程式裡移除，不再隨安裝包附帶；收款碼只在卡片展開時才解碼，收起就釋放記憶體。

音樂

歌詞會先認歌名是哪一國的歌，再抓同一種語言的版本：日文、韓文歌不再拿到整份中文翻譯或羅馬拼音

日本、韓國歌在網易雲、QQ 音樂常同時有原文、中文翻譯與羅馬拼音三種版本，先查到哪一份就回哪一份，島上因此經常出現「唱日文、顯示中文」。現在抓詞前先看歌名（看不出來才看歌手）屬於哪種語言：有假名就是日文、有諺文就是韓文、只有漢字是中文、只有英文字母是英文；抓回來的歌詞再用字元比例檢查一遍。日文歌沒有假名、韓文歌沒有諺文，就判定為中文翻譯或羅馬拼音，先當備選、繼續往下一個來源找原文；LRCLIB 同時列出原文與翻譯版本時也改成原文優先。只有全部來源都找不到原文，才退回備選顯示，而且翻譯與羅馬拼音不會寫進快取或本機歌詞庫，下次仍會重找原文。中文歌名不設限，粵語、台語、國語與中文歌取英文名的情況都照舊。

設定

「關於」頁補上上游與授權：原作者版本、MIT 條文與版本頻道都用繁中台灣用語寫清楚

台灣版衍生自上游開源專案，先前只在官網與 README 交代，程式內的「關於」頁看不到原作者與版本對照。現在「關於」多一張「上游與授權」卡：寫明本版是鬼島台灣版、目前跑的是開發版或正式版，原作是 Renly1994／xiaotang-daozai（Windows 桌面靈動島），上游原作者版本 0.6.66，台灣版自 0.6.106 起獨立編號、安裝包初始版本 0.6.00；並說明版本號與功能以鬼島自己的更新管道為準，上游版本號只當對照。MIT 授權保留原作者聲明與條文、LICENSE 隨程式附上，卡上直接給原作與授權條文連結。整段文案改寫成繁體中文台灣用語（版本、資訊、程式、連結），不再沿用上游的簡體寫法。

音樂

歌詞會自動對上歌手實際唱到的那一句：每首歌學一次位移，前奏不算進歌詞

歌詞檔的時間軸是「這首歌本身」的時間，但影片常有前奏、口白或開場畫面，播放器的進度還在前奏時，歌詞卻已經從第一句開始跑，看起來就像永遠慢好幾句。現在播放時會用聽歌辨識拿到的曲內秒數，對照播放器自己記的時間，算出這首歌的位移並存到本機（設定 → 音樂 會顯示「本曲自動對齊」與一顆歸零鍵）；同一首歌下次一開頭就從正確的那一句進場，不必再等辨識。順帶修掉一個會讓歌詞卡住的問題：以前辨識結果會一直改寫播放進度，播放卡幾乎每幀沿用同一個結果，位置就被釘在同一秒上，歌詞因此凍住不動；現在進度條維持播放器真實時間，只有歌詞換算成曲內時間，兩邊各自誠實。位移超過三分鐘視為認錯歌，不採用也不儲存；聽歌辨識關掉或還沒認出歌時，歌詞照舊按播放器時間顯示。

通知

手機連結轉送的 IG／Threads／Facebook／Messenger／LINE 通知，會回到各自的圖示，不再全算成「手機連結」

IG 的通知其實一直有被讀到，只是手機連結（Phone Link）轉送到電腦時，Windows 只登記「手機連結」這支程式，程式就把所有轉送通知都記在手機連結上，島上自然看不到 Instagram 的圖示與則數。現在改成先看通知第一段寫的來源（例如「Instagram · 杜貓 · 透過 手機連結」）再分派到 Instagram、Threads、Facebook、Messenger 或 LINE，認不出來才留在手機連結；同一則通知的深層連結照舊保留，點圖示會直接回到手機上那一則。另外瀏覽器通知的判斷也補上 Opera 與 Vivaldi。升級後第一次開啟會把舊存檔裡誤記在手機連結的數量清掉，實際未讀會由通知中心重新補上，不會出現兩邊重複計算。

安裝

開發版有自己的下載網址與啟動器：安裝在自己電腦，開啟就自動換成最新開發版

聽歌辨識：權限會跳視窗提醒，認出歌之後歌詞從正確段落進場

最新異動

更名為鬼島 桌面靈動島

軟體顯示名統一為「鬼島 桌面靈動島（Kuidao）」，版本資源、關於頁、安裝器與官網同步更新；安裝檔改用英文檔名 GuiDao-DynamicIsland-Setup，避免郵件與防毒誤判。

最新移除

官網移除生成標記與豆包字樣

官網不再出在任何 AI 生成標記，額度功能描述也撤掉豆包一詞；站內圖片本身無浮水印像素（邊緣全透明），顯示端若有角標屬平台疊加、不在檔案內。

最新新增

吉祥物可換形象

設定「外觀」新增吉祥物形象選單，預設島虎（石虎）；柴犬已補齊十二組表情動畫並可切換，貓、哈士奇、黃金獵犬待動畫完成後再開放。

最新移除

官網只留正式版

下載頁移除開發板卡片，改為單一安裝檔入口，並標明系統級安裝與程式清單可移除；首屏按鈕文案同步調整。

最新異動

音樂來源預設收起大陸播放器

網易雲、酷狗、汽水、酷我、波點、QQ 音樂不再自動上島；程式、歌詞與控制邏輯完整保留，改一個開關即可恢復。Spotify、Apple Music 與瀏覽器照常。

最新修正

天氣可選到行政區

修正查詢後綴只認簡體的問題，輸入「士林區」「內湖區」「北投區」都查得到，可把區加入城市清單；都會區各區天氣常與市中心不同，建議直接選到區一級。

最新更新

圖示與安裝方式調整

設定視窗與介面內的品牌圖示改用鬼島自己的標誌，不再沿用原作者圖案；安裝器改為系統級安裝，裝進 Program Files、註冊於 Windows 程式清單，移除時一併清除登錄與捷徑。

最新更新

信箱清單在地化

新增信箱的服務選單改列台灣可連線的服務：Yahoo 奇摩、iCloud、Gmail、Outlook／Hotmail 與自訂 IMAP；QQ、163、126、騰訊企業郵退出選單（舊帳號仍可解析）。同步程式已同步套用。

最新移除

移除贊助區塊

台灣版在設定「關於」頁不再顯示「支援作者」卡片與收款碼，改由常數關閉入口；同步程式會自動套用此設定，上游改版後也不會復原。

最新新增

官網與島虎上線

新增下載官網（單檔自包含，含功能介紹、雙版本下載、系統需求與常見問題）；品牌吉祥物定為台灣石虎「島虎」，官網與文宣共用同一素材。

最新新增

補入上游開發歷程

依原始碼倉庫的提交紀錄，把原始作者從首次開源到目前的演進，按安裝鏈、音樂、額度、通訊、天氣、外觀、效能、設定與穩定性九個方向整理進本站。

工具新增

解除封鎖工具納入倉庫

倉庫根目錄新增「解除封鎖.bat」，一鍵清除下載標記（Zone.Identifier），解決 SmartScreen 攔截；隨原始碼一起版控。

自動化新增

上游同步程式與雲端流水線

同步腳本：拉上游原始碼、轉換字串、修復比對鍵（歌詞來源、飛書標題、驗證碼詞表、天氣行政區對照表）、品牌改名、版本對齊，並輸出未命中清單；雲端工作流程定時執行，變更即提交、編譯、發佈。

介面新增

三套圖示與開發板角標

方形卡片版、透明標誌版、開發板角標版，各自封裝多尺寸 ICO；正式版與開發板分別內嵌，檔案哈希不同可辨。

權限更新

管理員清單與系統診斷修復

嵌入 requireAdministrator 清單；修復流程偵測系統組建、DirectX、WebView2、正黑體、執行庫，並執行映像健檢、系統檔掃描、DNS 清除、圖示快取重建、資源管理器重啟。

品牌異動

更名鬼島

顯示名、視窗標題、安裝器、版本資源、執行檔名全面替換；保留上游授權全文與衍生聲明。

在地化更新

繁體化與台灣用語

全專案字串轉換，介面用語改為設定、檔案、資料夾、網路、螢幕、滑鼠、桌布；微軟正黑體優先、十二小時制。
