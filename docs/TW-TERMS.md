## 刻意保留原字（專有名詞／服務名）

微信、QQ、飛書／飞书、釘釘、企業微信、網易雲音樂、QQ 音樂、酷狗音樂、汽水音樂、波點音樂、DeepSeek、Kimi、Claude、Gemini、Codex、WorkBuddy、Kiro、飛書文件、和風天氣。

理由：這些是服務原名或品牌，改了會讓使用者對不上系統裡的視窗標題、媒體工作階段或官網名稱；其中飛書、汽水音樂另外在程式內同時保留簡體字串做比對（見下）。

## 為維持功能而保留簡體的地方（不要「順手」改掉）

| 位置 | 字串 | 原因 |
|---|---|---|
| `src/lyrics.rs` `is_soda()` | `"汽水音乐"` | 系統媒體工作階段回報的是簡體原名 |
| `src/smtc.rs` 音樂來源判斷 | `"汽水音乐"` | 同上 |
| `src/messenger/desktop.rs` `FEISHU_TITLES` | `"飞书"` | 簡體版飛書的主視窗標題 |
| `src/otp.rs` 關鍵詞表 | 「订单／单号／快递…」簡體組 | 對岸與跨境郵件的驗證碼、訂單詞彙 |
| `src/weather.rs` `PROVINCE_CAPITALS` | 簡體省名（宁夏、新疆…） | 使用者輸入簡體省名時仍能查到省會 |
