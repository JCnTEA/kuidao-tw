# P2：現貨金價

插件倉分支 `feat/official-gold`，插件 ID `daozai.gold`。邏輯層現在就能開工，畫面層依賴 A、B、C；投稿依賴 P0。設計稿：「理想版 · 現貨金價」。共同規則見 [README](README.md)。

參考 `spike/examples/gold-price`，它已經跑通 xaus.com 的人民幣每克報價。

## 數據

- `network.hosts: ["xaus.com"]`，兩個來源：
  - `usd`：`https://xaus.com/api/v1/spot?currency=USD&unit=ounce&compact=1`
  - `cny`：`https://xaus.com/api/v1/spot?currency=CNY&unit=gram&compact=1`
- 換算由 xaus 完成，不需要另外的匯率來源。
  - 返回 `fx_stale: true` 時，人民幣視圖在價格下標「匯率待更新」。
  - 美元視圖不受影響。
- 刷新：`minRefreshSeconds: 60`，默認 300，用戶可調。
- 存儲：兩種單位各保留最近 48 個價格點，帶時間戳。
  - 「1周」「1月」區間按小時、按天降採樣後另存，各 48 個點。
- `attribution: {label: "xaus.com"}`。

## 設置

| 鍵 | 類型 | 說明 |
| --- | --- | --- |
| `unit` | choice | `usd`（美元/盎司）、`cny`（人民幣/克），默認 `cny`，也可在頁面上切換 |
| `range` | choice | 1日、1周、1月 |
| `alert_usd` | number | 美元提醒價，0 表示不提醒 |
| `alert_cny` | number | 人民幣提醒價，0 表示不提醒 |
| `up_color` | choice | 紅漲綠跌（默認）、綠漲紅跌 |

## 界面

整頁畫布，高 196。

- **左欄**（寬 138）：
  - 單位切換鈕（畫布點按區，觸發 `action` 修改 `unit`）；
  - 主價格，30 號字、800 字重；
  - 漲跌色塊：三角加漲跌額和百分比；
  - 三行小字：摺合另一單位、今日高、今日低。
- **右欄**：
  - 區間切換鈕；
  - 面積圖：帶縱軸價格、橫軸時間、末點發光、提醒價虛線和標籤；
  - 鼠標懸停顯示十字線和讀數（B 的 `tips`）。
- **頁腳**：數據來源、頁碼點（宿主）、更新時間。
- 切換單位或區間時，整張圖用 `animate` 平滑過渡。

## 其他行為

- 提醒：
  - 價格從提醒價一側跨到另一側時，發一次 `notice`，例如「金價漲破 ¥950」。
  - `notice.id` 帶單位、價位和方向，同方向不重複。
- 常駐：
  - 常駐小畫布顯示「金」字加當前單位的價格加 30 寬的迷你走勢。
  - 走勢線顏色按漲跌取。
- 取數失敗：
  - 撤下舊讀數，顯示「數據源暫不可用」，常駐返回 null。
  - 退避由宿主負責。
- 全文不出現「建議」「看漲」「看跌」等字樣。

## 驗收

- 截圖：美元視圖、人民幣視圖、懸停讀數、匯率待更新、取數失敗。
- 用本地假數據跑單元測試：
  - 單位切換；
  - 區間降採樣；
  - 提醒跨線去重；
  - `fx_stale`；
  - 漲跌配色設置。
