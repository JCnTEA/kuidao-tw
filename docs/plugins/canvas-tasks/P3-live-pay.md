# P3：實時工資

插件倉分支 `feat/official-live-pay`，插件 ID `daozai.live-pay`。邏輯層現在就能開工，畫面層依賴 A、B、C；投稿依賴 P0。設計稿：「理想版 · 實時工資」。共同規則見 [README](README.md)。

參考 `spike/examples/live-pay` 的計算部分。

## 設置

| 鍵 | 類型 | 默認 |
| --- | --- | --- |
| `salary` | number，元/月 | 無，未填時頁面提示去設置 |
| `start`、`end` | time | 09:00、18:00 |
| `breaks` | list，最多 4 段 | 一段「12:00–13:30，不計薪」 |
| `days` | weekdays | 一至五 |
| `pinned_show` | choice | 金額（默認）、下班倒計時、兩者輪換 |

`breaks` 每段有三個子項：

- `from`：time，開始時間；
- `to`：time，結束時間；
- `paid`：switch，這段是否計薪，默認關。

規則：

- 用戶可以刪掉全部段，表示無午休。
- 各段必須在上下班之間且不重疊，設置頁對不合規的段給出提示。

日薪 = 月薪 ÷ 當月工作日數；每秒 = 日薪 ÷ 當天計薪秒數（不計薪的休息段不算在內）。

## 界面

整頁畫布，高 200。

- **標題下一行**：「今天已賺」加每秒增量。
- **計價器**：
  - 「¥」加每位一格的數字。整數位數按金額變化，小數兩位。
  - 用 `counter` 綁定，開 `roll`，最後一位用強調色。
- **遊戲經驗條**，高 16：
  - 左邊是「LV.N」，N 為當前第幾個工作小時。
  - 進度用 `progress` 綁定，從上班到下班。
  - 填充帶斜條紋，開 `loop: flow`，有外發光。
  - 每小時一條分隔線。
  - 每個休息段用橙色斜紋標出。不畫飯碗等檢查點圖標。
  - 末端放終點旗。
  - 島仔沿進度移動：用 B 的 `pet` 節點，`at` 綁定上下班進度。
    - 工作時：`mood: "expressions"`，`motion: "run"`。島仔在進度頭原地跑跳，表情隨機輪換。
    - 不要自己畫島仔的臉，由宿主繪製，這樣會跟隨用戶的表情包。
- **底部一行**：
  - 左邊「第 N 小時 · 本小時已賺 ¥x」。
  - 右邊綠色膠囊「距離通關 HH:mm:ss」，用 `countdown` 綁定。

## 狀態切換

- 用 `next_refresh_at` 在上班、每個休息段的開始和結束、下班這幾個時刻刷新。
- 休息段內：
  - 經驗條換成橙色回血條。
  - 島仔切到 `mood: "sleeping"`、`motion: "none"`，旁邊用文字節點冒「Zz」（`loop: pulse`）。
  - 不計薪的段計價器停住；計薪的段照常跳動。
- 下班後：
  - 顯示「通關！今天到手 ¥x」。
  - 島仔切到 `mood: "praised"`、`motion: "bob"`，旁邊插一面旗；撒一次彩紙（`burst`），同一天只播放一次。
- 休息日：顯示「今天不打怪」和距離下個工作日上班的倒計時。
- 下班時發一次 `notice`：「下班啦」。正文不寫金額。

## 常駐

- 常駐小畫布按 `pinned_show` 顯示：
  - 金額：金幣圖標加跳動金額，帶 `roll`；
  - 下班倒計時：旗子圖標加倒計時；
  - 兩者輪換：每 8 秒切換一次，隨常駐輪播節奏走。
- 插件本身不做打碼。

## 驗收

- 截圖：
  - 上班中；
  - 休息段（計薪和不計薪各一張）；
  - 無午休；
  - 通關；
  - 休息日；
  - 常駐的三種顯示。
- 單元測試：
  - 當月工作日數；
  - 多個休息段、無休息段、計薪段對每秒金額的影響；
  - 休息段越界或重疊的校驗；
  - 各狀態切換時刻；
  - 跨午夜的上下班設置（如 22:00–06:00）。
- 用 `DAOZAI_FRAME_TRACE=1` 確認：只有經驗條在流動時，幀間隔正常，島收起後不再出動畫幀。
