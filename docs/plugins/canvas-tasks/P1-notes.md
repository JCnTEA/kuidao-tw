# P1：便籤本

插件倉分支 `feat/official-notes`，插件 ID `daozai.notes`。邏輯層現在就能開工，畫面層依賴 A、B、C；投稿依賴 P0。設計稿：「理想版 · 便籤本」。共同規則見 [README](README.md)。

## 插件

- 能力：`status.page`、`status.canvas`、`action`、`event`、`notice`、`storage`、`island.pinned`、`settings`。
- 設置：
  - `pin_mode`（choice）：指定一張、最新一張、置頂輪播；
  - `pin_id`（隱藏的 text，記錄被指定的那張）。
- 存儲：`{notes:[{id,text,color,source,pinned,done_at,created_at}], current, next_id}`，不設條數上限。

## 界面

整頁畫布，高 230。

- **左側紙堆**，寬 168：
  - 最上面一張完整顯示當前便籤：第一行粗體，其餘正文。
  - 後面露出兩張紙的邊。
  - 底部三個按鈕：複製、完成、常駐。
- **紙堆下方**是輸入框和「＋」，用 `fields`（`multiline`）加 `actions`。也可以用畫布的點按區配合標準輸入框，以設計稿為準。
- **右側**：
  - 搜索框（`fields`）。
  - 搜索框下面是分組列表：置頂、今天、昨天、更早。
  - 每行有顏色條、標題、時間。常駐中的那一行末尾加一個藍色小條。
  - 列表放在滾動區裡。
- 點列表某一行，`action` 把它設為 `current`；紙堆用 `animate` 讓新紙片從右側滑到最上面。
- 完成：
  - 這一行劃線後淡出，提示條顯示「撤銷」3 秒。
  - 3 秒後移入「已完成」，30 天後清理。
- 置頂不限條數，置頂組內按置頂時間排序。
- 顏色按來源取：手寫黃 `#FFE58A`、專注紅 `#FF8A7A`、粘貼藍 `#8FD3F5`。

## 其他行為

- `focus.finished` 事件：自動新建一條紅色便籤「完成一次專注 · N 分鐘」。
- 常駐：
  - 用常駐小畫布：紙片色塊加一行文字，文字太長時滾動一遍。
  - 顯示哪一張按 `pin_mode` 決定。
  - 沒有可顯示的便籤時返回 `pinned: null`。
- 搜索：腳本按輸入過濾，空搜索顯示全部。
- 存儲接近 256 KiB 時，狀態行提示「便籤較多，可在詳情裡導出備份」。

## 驗收

- 和設計稿同尺寸的截圖：正常狀態、完成後撤銷提示、空狀態。
- 單元測試（JS 部分用插件倉的測試腳本，或在島仔裡用 `sdk_spike` 跑腳本）：
  - 添加、完成、撤銷、置頂、搜索、常駐三種模式；
  - 專注事件。
- 1000 條便籤時，刷新仍在 30 毫秒限制內，輸出不超過 64 KiB。超出時只把可見部分放進畫布。
