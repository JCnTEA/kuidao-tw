設計說明
  • 主角是計價器式數字：每位一格，變化時那一格向上翻，最後一位用綠色。
  • 下面是一條遊戲經驗條：一天就是一關，每小時一格，左邊寫「LV.5」表示第 5 小時；條紋會緩慢流動。
  • 休息時段在設定裡自己填：可以加多段（午休、下午茶），也可以一段都不填（無午休）。經驗條上用橙色斜紋標出。
  • 進入休息時段：進度條變成橙色回血條，島仔閉眼冒 Zz，計價器暫停（每段可單獨設成「計薪」）；結束自動醒來。
  • 常駐條顯示內容可選：金額、下班倒計時、兩者輪換。隱私由使用者自己決定，插件不強制打碼。

蓄力 起跳 · 眯眼 空中 · 愛心 落地 · 揚塵 斜眼
  • 動作：原地「蓄力 → 起跳 → 空中 → 落地揚塵」循環，一次約 0.7 秒，像遊戲載入頁的小人。只在展開且可見時播放，收起即停。
  • 表情：工作時每 6–10 秒隨機換一個現有表情（wink、得意、害羞、愛心、斜眼…），跟隨使用者裝的表情包。
  • 休息時段改為睡覺姿態，通關時用「被誇」表情舉旗。
  • 島仔由島仔自己畫（畫布裡的 pet 節點），插件只給位置、動作和狀態，不畫臉。
