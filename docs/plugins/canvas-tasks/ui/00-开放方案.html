開放方案：標準組件 + 自繪畫布

不再給每種設計補一個組件。開放一個「自繪畫布」：插件描述要畫的圖形，島仔負責畫、縮放、主題、幀率和安全。五個官方插件都用它來做，順便當樣例。

三層結構
標準組件（已有，保留）狀態行、指標、列表、折線、計數、時鐘、倒計時、按鈕、輸入框。零設計也好看，適合工具型插件。
自繪畫布（新增）矩形、圓角、圓、弧、線、路徑、文字、包內圖片、分組、漸變、陰影、發光、裁剪。可以和標準組件混排，也可以整頁都是畫布。
宿主實時值（兩邊共用）現在時間、計數器、倒計時、城市時鐘、某段時間的進度。畫布裡寫「綁定」，島仔每幀算，腳本不用每秒跑。
為什麼這樣比逐個補組件好
  • 做一次渲染器，所有插件都受益；新設計不需要我們再寫代碼。
  • 作者的上限由他的審美決定，不由我們的組件清單決定。
  • 仍然是數據不是代碼：不能聯網取圖、不能讀文件，島仔能檢查和限流。
插件返回什麼（以「日子」的日曆頁為例）
// refresh() 返回，和 status 同級
canvas: { height: 196, nodes: [
  { rect: [0, 0, 150, 196], r: 10, fill: "#FBF8F1", shadow: "lg" },
  { rect: [0, 0, 150, 30], r: [10,10,0,0], fill: "$accent" },
  { text: "距 元旦", at: [10, 19], size: 11, weight: 700, color: "#fff" },
  { text: "{days}", at: [75, 100], size: 62, weight: 900,
    align: "center", color: "$accent",
    bind: { days: { countdown: 0, unit: "day" } } },
  { arc: { c: [75, 100], r: 64, sweep: { progress: ["2026-10-08", "2027-01-01"] } },
    stroke: "$accent", width: 4, glow: true },
  { hit: [0, 0, 150, 196], action: "open-calendar", hover: { lift: 2 } }
]}
// 常駐條：同樣的格式，限高 22、寬 156
pinned: { canvas: { nodes: [ … ] } }
護欄
  • 字體預設用島仔自帶的；使用者裝了「字體包」插件後，畫布可按名字引用（缺字時回退到島仔字體）。顏色可寫 $accent、$text、$muted、$card，換皮膚自動跟隨。
  • 每頁最多 1500 個圖元，圖片只能來自插件包（合計 512 KiB）。
  • 動畫只能聲明（數值變化時過渡、有限次的循環），不能讓腳本每幀跑。
  • 繪製超時自動降級為靜態畫面，並在開發調試裡提示作者。
  • 隱私交給使用者：插件不強制打碼，使用者可用島仔已有的「截圖和錄屏中隱藏」等設定。

做完：五張理想稿完整還原。
三作者工具裡的實時預覽、尺寸和對比度檢查、集市審核時的截圖比對。
做完：社區作者能放心做好看的插件。
已有的照常保留
  • 狀態頁標準組件、設定類型、聯網取數、提醒、事件、存儲都不變。
  • 老插件不用改；想變好看的插件只需多返回一個 canvas。
還需要補的小項
  • 設定類型 timezone：中文城市搜索並帶出時區（世界時鐘）。
  • 多行文本輸入（便籤）。
  • 插件私有存儲導出（便籤不限條數時用）。
  • list 設定的子項支援 icon、color（日子選圖標和顏色）。
  • 字體包：新的外觀資源包類型 appearance.font。
