# P5：日子（倒計時 + 節假日合併）

插件倉分支 `feat/official-days`，插件 ID `daozai.days`。邏輯層現在就能開工，畫面層依賴 A、B、C；投稿依賴 P0。設計稿：「理想版 · 日子」。共同規則見 [README](README.md)。

參考 `spike/examples/countdown` 和 `spike/examples/holidays`：節假日數據格式和日曆標註的寫法沿用它們。

## 清單

- 歸屬 `owner: "tasks"`。
- 能力：`card`、`calendar.marker`、`status.page`、`status.canvas`、`timer`、`settings`、`action`、`notice`、`island.pinned`。
- 數據文件：`data: ["holidays-2026.json", "holidays-2027.json"]`。隨包帶當年和次年的數據；次年數據未公佈時文件裡標 `pending: true`。

## 設置

`days`：`list`，最多 20 項。每項包含：

| 子項 | 類型 | 說明 |
| --- | --- | --- |
| `name` | text | 最多 12 字 |
| `date` | date | 日期 |
| `kind` | choice | 倒數、紀念日（正數）、生日 |
| `yearly` | switch | 每年重複 |
| `icon` | icon（C 新增） | 默認按類型：倒數是旗子，紀念日是愛心，生日是蛋糕 |
| `color` | color（C 新增） | 默認按類型 |
| `pinned_text` | text | 這個日子的常駐文字模板，最多 24 字 |

其他設置：

- `pinned_day`：choice，「最近的那一天」或列表裡的某一項；
- `show_holidays`：switch，默認開。

## 界面

整頁畫布，高 200。

**左側手撕日曆**，寬 150：

- 米白紙、紅色頁眉寫「距 名稱」和「放假 N 天」，頁眉上有兩個裝訂孔，後面露出兩頁紙邊。
- 中間是大號紅字天數，下方寫「天」。紀念日寫「已 N 天」。
- 底部寫日期和星期。
- 顯示的是「最近的那一天」，節假日和自己的日子一起比較。
- 每天 0 點刷新時，用 `animate` 讓舊頁向右下飛出，新頁露出。

**右側**：

- 頂部一行：篩選鈕「全部 / 節假日 N / 我的 N」（畫布點按區），右側顯示當週的調休提醒。
- 下面是車票列表，放在滾動區裡：
  - 每個日子一張，高 32，按日期排序。
  - 左段寫名稱和「日期 · 放假 N 天 / 每年」，右段隔一條虛線寫天數。
  - 兩側有半圓缺口。
  - 車票顏色：法定假期按節日取色，自己的日子用設置裡的 `color`。
- 當天：日曆頁顯示「今天」，車票這一張加高亮邊框。

## 待辦卡和日曆標註

保留首版的寫法：

- 待辦卡寫最近一天和當週調休；
- 日曆當天下方標註節日名，放假標「休」，調休上班標「班」。

## 常駐

- 用常駐小畫布，顯示 `pinned_day` 選中的日子：該日子的圖標、顏色和常駐文字。
- 模板支持 `{名稱}`、`{天數}`、`{日期}`、`{星期}`。
- 未填模板時用默認寫法：
  - 倒數：「名稱 還有 N 天」；
  - 紀念日：「名稱 N 天」；
  - 生日：「名稱 生日還有 N 天」。
- 當天改用「今天是 名稱」。

## 提醒

- 紀念日滿整百、整千天當天發一次 `notice`。
- 生日當天發一次 `notice`。

## 驗收

- 截圖：
  - 普通日；
  - 當天是節日；
  - 只有自己的日子（關掉節假日）；
  - 有調休的一週；
  - 常駐顯示紀念日。
- 單元測試：
  - 倒數、紀念日和生日的天數計算；
  - 閏年 2 月 29 日的生日；
  - 次年數據 `pending` 時的顯示；
  - 模板替換；
  - 篩選。
