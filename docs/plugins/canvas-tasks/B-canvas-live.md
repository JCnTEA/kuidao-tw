# B：實時綁定、動畫與交互

分支 `feat/plugin-canvas-live`，從 `feat/plugin-canvas` 開出。共同規則見 [README](README.md)。

A 定好了數據結構。本任務讓畫布動起來、能點：

- 綁定求值；
- 數字翻動；
- 過渡和循環動畫；
- 點按與懸停；
- 滾動區。

## 先讀

- A 的說明和代碼。
- `src/plugin_status_realtime.rs`：現有 counter、clock、countdown 的計算方式和重繪安排，可以複用。
- `spike/plugin_interactions.rs`：按鈕點擊、調用隊列、舊點擊作廢的機制。
- `src/main.rs` 裡的 `page_animating`、`interactive_transition`：兼容渲染下動畫幀的交付方式。

## 綁定

畫布的 `binds` 定義名字和來源，節點裡引用這些名字。

```json
"binds": {
  "money": {"counter": {"start_value": 0, "per_second": 0.0167, "start_at": 1795400000, "decimals": 2}},
  "left":  {"countdown": {"target_at": 1795431600, "format": "HH:mm:ss"}},
  "work":  {"progress": [1795392000, 1795424400]},
  "ny_h":  {"clock_angle": {"zone": "America/New_York", "hand": "hour"}},
  "now":   {"now": "HH:mm"}
}
```

| 來源 | 結果 |
| --- | --- |
| `counter` | 格式化後的數字文字，同時可作數值使用 |
| `countdown` | 格式化文字，`format` 與現有倒計時一致；同時可作剩餘秒數使用 |
| `progress` | 0 到 1 的數值：現在處在 `[開始, 結束]` 之間的位置，越界時取 0 或 1 |
| `clock_angle` | 指定時區現在的時針或分針角度（度） |
| `now` | 格式化的現在時間，可加 `zone` |
| `daylight` | 指定時區現在是否在 `[開始時, 結束時]` 之內，結果為 0 或 1，用於按日夜換色 |

用法：

- 文字裡寫 `{money}` 直接替換。
- 數值字段寫 `{"bind":"work","map":[0,210]}`，把 0 到 1 線性映射到區間。可用於弧的 `sweep`、矩形寬度、座標、旋轉角度、透明度。
- 顏色字段寫 `{"bind":"day","pick":["#2E64B5","#FFC43D"]}`，按 0 或 1 取色。

重繪安排：

- 按所有綁定裡最近的變化點安排下一次重繪：顯示到秒的每秒一次，顯示到分鐘的每分鐘一次，`progress` 按像素精度推算。
- 頁面不可見、島收起或插件停用時停止計算。

## 動畫

- **數字翻動**：文字節點加 `"roll": true` 後，數字變化時只有變了的那幾位向上翻。翻動時長 220 毫秒。
- **過渡**：節點加 `"animate": {"ms": 300, "ease": "spring"}`。兩次輸出之間同一 `id` 的節點，位置、尺寸、角度、透明度、顏色平滑過渡；新增節點淡入，消失的節點淡出。`ms` 範圍 120 到 1200。
- **循環**：節點加 `"loop": {"kind": "pulse" | "flow" | "bob" | "spin", "period_ms": 1600}`。
  - 同時最多 8 個節點循環，週期至少 800 毫秒。
  - 循環幀率最高每秒 30 幀，只在頁面展開且可見時運行。
  - 用於工資經驗條的條紋流動、小人上下浮動、午休打呼。
- **一次性效果**：`"burst": "confetti"`，在節點位置撒一次彩紙，用於通關。同一 `id` 只播放一次。
- 有動畫進行時，這些幀在兼容渲染下要走交互幀，幀率要達到每秒 60 幀，參考 `page_animating`。動畫結束後回到靜止，不產生多餘幀。

## 島仔節點

畫布可以放一個由宿主繪製的島仔，插件不用自己畫臉。

```json
{"pet": {"at": [226, 8], "size": 28, "mood": "expressions", "motion": "run", "id": "pet"}}
```

- 繪製複用 `src/pet.rs` 和 `src/pet_expressions.rs`：同樣的造型、表情圖集和配色，並跟隨用戶安裝的表情包。
- `mood` 可選值：
  - `expressions`：每 6 到 10 秒隨機換一個現有表情，共 12 種，即 wink、smug、blush、delighted、side-glance、praised、heart、giggle、shy-peek、scan、peek、search；
  - `sleeping`：睡覺；
  - `happy`：開心；
  - `praised`：被誇；
  - 具體某個表情名。
- `motion` 可選值：
  - `run`：原地跑跳循環，像遊戲加載頁的小人。一個循環約 700 毫秒，依次是蓄力壓扁、起跳拉長、空中、落地揚塵（地面兩三個小灰點）。
  - `bob`：輕輕上下浮動。
  - `none`：不動。
- `at` 可以用綁定，例如 `{"bind":"work","map":[0,360]}`，讓島仔跟著進度條走。
- 動作和表情都算循環動畫，計入 B 的循環上限，只在展開且可見時播放，幀率規則與其他循環相同。
- 每個畫布最多 1 個島仔節點；常駐小畫布不支持。

## 交互

- 節點加 `"hit": {"action": "id"}`，也可以寫 `{"open": "https://…"}` 或 `{"copy": "文字"}`。規則與現有按鈕一致：
  - `open` 只能打開 `network.hosts` 裡的地址；
  - `copy` 最多 2000 字；
  - 舊點擊在輸出更新後作廢。
- 點擊區域取節點的外框，分組取整組外框。每個畫布最多 64 個點擊區域。
- 懸停：`"hover": {"opacity": 1, "lift": 2, "fill": "#…"}`。宿主在懸停時套用這些樣式，用 `animate` 時長過渡。
- 滾動區：分組加 `"scroll": {"axis": "y", "content": 420}`，內容超出時可以用滾輪在區域內滾動。
  - 滾動區裡的滾輪不能觸發翻頁。參考 `set_page_scroll_area` 的現有做法。
  - 滾動位置在同一插件的多次刷新之間保留。
- 鼠標在畫布上移動時，宿主把相對座標傳給腳本是**不做**的。圖表懸停讀數用下面的「懸停提示」實現。
- 懸停提示：折線節點加 `"tips": [{"x": 140, "label": "12:40", "value": "4,106.2"}, …]`。鼠標靠近某個 x 時，宿主畫十字線和提示框，樣式統一。

## 驗收標準

- 單元測試覆蓋：
  - 每種綁定在邊界前後的取值；
  - 跨午夜和夏令時切換的 `clock_angle`；
  - 數值映射與取色；
  - 動畫數量和週期上限；
  - 點擊區域上限；
  - 舊點擊作廢；
  - 滾動區與翻頁不衝突。
- 演示插件擴展為「會動」的版本：一個跳動金額、一個隨時間走的進度弧、一個指針錶盤、一個可點按的切換和一個滾動列表。
- 在 60 Hz 屏幕上使用 release 測試版進行 DX12 兼容渲染驗收，開啟 `DAOZAI_RENDERER=wgpu` 和 `DAOZAI_FRAME_TRACE=1`。在隔離配置的診斷目錄確認兼容後端及分層顯示已生效。
- 展開實時畫布，累計採集至少 45 個數字翻動期間相鄰交互幀的間隔。展開靜止畫布，待翻頁結束後採集 30 秒。用 `python spike/check-canvas-frames.py <動畫日誌> <靜止日誌>` 校驗。相鄰交互幀間隔約 17 毫秒，靜止時無動畫幀及高頻交互讀回。進入交互幀的更新入口差值包含普通幀的節流等待。靜止採樣期間如出現連續日誌輪轉，保留輪轉前後的日誌用於核對。
