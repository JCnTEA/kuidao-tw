# C：常駐小畫布、字體包與設置補項

分支 `feat/plugin-canvas-extras`，從 `feat/plugin-canvas` 開出，可以和 B 同時做。共同規則見 [README](README.md)。

## 先讀

- `spike/pinned.rs`：常駐位的數據、輪播和讓位規則。
- `spike/appearance_assets.rs`：皮膚、圖標、表情資源包的格式和安裝。
- `spike/script_settings.rs`：設置類型的解析、保存和繪製。
- 插件詳情和「已安裝」列表的相關代碼，`spike/local_ui.rs`。

## 1. 常駐小畫布

- `pinned` 新增 `canvas` 字段，與現有的 `text`、`value`、`icon` 二選一。
- 尺寸：高 22，寬最多 156，作者用 `width` 聲明實際寬度。
- 節點最多 60 個，支持 B 的綁定和數字翻動，不支持點按區域（點常駐條仍是打開插件頁）。
- 現有的輪播、讓位、開關規則不變。
- 驗收樣例：用迷你進度環 + 跳動金額，和色塊 + 一行滾動文字各做一個。

## 2. 字體包

- 新的外觀資源包能力 `appearance.font`，運行環境 assets，歸屬 appearance，可以和其他外觀包同時啟用。
- 入口 JSON 寫法：`{"fonts":[{"name":"站酷快樂體","file":"zcool-kuaile.ttf"}]}`，最多 4 個字體文件。
- 字體文件格式為 TTF 或 OTF，單個最多 8 MiB，整包最多 16 MiB。這些資源包的大小上限需要單獨放寬。
- 包裡必須帶 `LICENSE` 或 `OFL.txt`，安裝時檢查文件存在。
- 啟用後，字體以 `plugin:<名字>` 註冊進 egui 字體表。畫布文字節點寫 `"font":"站酷快樂體"` 即可使用，未安裝或缺字時回退到島仔字體。
- 停用或卸載字體包後，引用它的畫布回退到默認字體，不報錯。
- 本任務不做「全局替換島仔字體」，只給畫布使用。

## 3. 設置補項

- **時區類型 `timezone`**：設置頁顯示一個可搜索的選擇框。
  - 輸入中文城市名或國家名，例如「紐約」「美國」，列出匹配的城市和它的 IANA 時區。
  - 保存 IANA 名稱。
  - 內置一份城市表（至少 300 個常用城市，中文名 + 時區），放在 `src/` 的數據文件裡。
  - 可以作為 `list` 的子項使用，世界時鐘靠它添加最多 10 個城市。
- **多行文本**：`text` 設置和狀態頁 `fields` 都新增 `multiline: true`。
  - 輸入框隨內容長高，最多 6 行。
  - 回車換行，Ctrl+Enter 提交。
- **list 子項的圖標和顏色**：
  - 新增子項類型 `icon`：從宿主內置圖標裡選，至少提供愛心、蛋糕、戒指、飛機、星星、禮物、旗子、日曆、咖啡、硬幣、太陽、月亮。
  - 新增子項類型 `color`：從 8 個預設色裡選。
  - 兩種都保存為名字字符串。畫布可以用 `{"icon":"heart","rect":[…]}` 節點畫出同一套圖標。
- **私有存儲導出和導入**：在插件詳情的「···」菜單加「導出數據」「導入數據」。
  - 導出的 JSON 包含插件 ID、dataVersion 和 storage。
  - 導入時核對插件 ID 和 dataVersion。
  - 便籤本不限條數，靠這個做備份。

## 驗收標準

- 單元測試覆蓋：
  - 常駐畫布的尺寸和節點上限；
  - 字體包的格式、大小、許可文件檢查；
  - 字體回退；
  - 時區搜索中文匹配；
  - 多行文本的保存；
  - icon、color 子項的取值校驗；
  - 導入時 ID 不符拒收。
- egui 測試：常駐小畫布在兩種皮膚、左右停靠和頂部停靠下都不越界。
- 演示：裝一個開源中文字體包，演示插件的標題改用這個字體。
