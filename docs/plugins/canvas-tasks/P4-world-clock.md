# P4：世界時鐘

插件倉分支 `feat/official-world-clock`，插件 ID `daozai.world-clock`。邏輯層現在就能開工，畫面層依賴 A、B、C；投稿依賴 P0。設計稿：「理想版 · 世界時鐘」。共同規則見 [README](README.md)。

## 設置

- `cities`：`list`，最多 10 項。每項包含：
  - `name`：text，顯示名，默認取城市表裡的中文名；
  - `zone`：C 新增的 `timezone` 類型。
- `pinned_city`：choice，從已添加的城市裡選一個常駐。
- 清單聲明 `timezones: true`。

## 界面

整頁畫布，高度隨城市數變化：

- 1–5 個城市：一行錶盤，錶盤直徑放大到 64；
- 6–10 個城市：兩行，每行 5 個，錶盤直徑 46；
- 頁面高度範圍 236 到 344。

**錶盤**：

- 只畫 12、3、6、9 四個刻度。時針粗、分針細，端頭為圓角。
- 指針角度用 `clock_angle` 綁定，按分鐘走。
- 當地 6–18 點：米白盤面 `#F4F1EA`，深色指針，中心點橙色。
- 其餘時間：深藍盤面 `#101626`，淺色指針，中心點藍色。
- 換色用 `daylight` 綁定。
- 錶盤下方依次是：城市名、數字時間（`now` 綁定，帶 `zone`）、「昨天 / 今天 / 明天 · ±Nh」。
  - 半小時時區寫成「+5.5h」。

**24 小時色條**：

- 每個城市一行，高 5，左側是城市名。
- 橫軸是本機時區的 0–24 點。
- 每行把該城市當地 9–18 點對應的區段畫成黃色 `#FFC43D`，其餘為藍色 `#2E64B5`。
- 一條白色豎線表示現在，用 `progress` 綁定當天 0 點到 24 點。
- 底部寫 0、6、12、18、24 刻度和「本機時區」名稱。

**點按**：點任一表盤，`action` 把它設為常駐城市。

## 常駐

常駐小畫布：迷你錶盤（隨日夜換色）加城市名和數字時間。

## 驗收

- 截圖：3 個城市、10 個城市、跨日期變更線的城市（如奧克蘭）、正在切換夏令時的城市。
- 單元測試：
  - 色條區段在跨午夜時拆成兩段；
  - 半小時和 45 分鐘時區（加德滿都）；
  - 「昨天 / 明天」判斷；
  - 城市數量與頁面高度的對應。
