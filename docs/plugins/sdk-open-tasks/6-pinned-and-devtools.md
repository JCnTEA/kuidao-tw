# 第 6 步：島上常駐位與開發調試

本步有兩部分：

- **島上常駐位**：島收起時，也能顯示插件提供的一小段內容，比如今日工資、金價、下個假期還有幾天。
- **開發調試**：降低作者自己動手寫插件的門檻，減少他們為"能不能做"來問。

分支用 `feat/plugin-pinned-devtools`，共同規則見 [README](README.md)。

## 先讀

- `src/app.rs`：島收起時膠囊裡顯示什麼、怎麼排優先級。可以搜現有的常駐訊息，例如音樂、未讀數、額度。
- `spike/local.rs`：`tick_features`、`cards`。
- `spike/plugin_author_ui.rs`：開發者工具。
- `spike/local.rs` 裡 `--plugin-test`、`--plugin-pack` 的實現。
- `docs/plugins/sdk-v1-design.md` 中"常駐、固定、臨時卡 · 待宿主實現"那一行。

## 要做的

### 島上常駐位（能力 `island.pinned`）

**插件怎麼提供內容**

- 輸出裡帶 `pinned:{text, value?, icon?}`，`text` 最多 12 個字。
- `value` 可以引用第 3 步的 `counter` 或 `countdown` 參數，由宿主在本地跳動顯示；也可以標 `sensitive: true`。

**使用者怎麼選**

- 使用者在插件設定裡打開「在島上常駐顯示」，預設關閉。
- 同一時間最多 3 個插件常駐，按使用者排定的順序輪流顯示，在島的設定裡調整順序。
- 超過 3 個時提示使用者替換哪一個。

**和本體內容怎麼排**

- 本體正在顯示的高優先級內容時插件不出現，包括來電、通知彈出視窗、音樂歌詞。
- 具體優先級參考現有規則，寫進文檔。

**怎麼畫**

- 先用現有膠囊文字樣式畫出能用的版本。最終視覺由驗收方來做。
- 實時值的重繪頻率同第 3 步：秒級每秒重繪一次，不要每幀重繪。

**啟停**

- 插件停用、所屬模塊關閉、或使用者關掉常駐時，立即撤下。

### 開發調試

- **儲存後自動重載**：開發者工具裡勾選「監視文件變化」後，從本地清單安裝的插件在 `plugin.json`、入口腳本或數據文件儲存後 1 秒內重新安裝並刷新。舊數據保留。只對本地開發包生效，集市安裝的不受影響。
- **腳本日誌**：腳本里可以用 `console.log`，每次調用最多 20 行、每行 200 字。在開發者工具裡查看最近 100 行，生產環境不寫磁盤。
- **模擬輸入**：`--plugin-test plugin.json --input mock.json` 用指定的 settings、storage、now 和 sources 跑一次 refresh，列印輸出和用時，方便作者不聯網也能試。
- **錯誤定位**：腳本報錯時顯示行號和列號。
- **能力自檢**：`--plugin-test` 輸出這個清單用到的能力，以及每項在當前宿主上是"可用""實驗"還是"未支援"。
- **教程**：在 `spike/plugin_guide_ui.rs` 的教程裡寫明這些工具怎麼用。

## 驗收標準

**單元測試**至少覆蓋：

- 常駐位最多 3 個；
- 停用後撤下；
- 高優先級內容出現時讓位；
- 敏感值打碼；
- 文件變化觸發重載，以及防抖；
- 日誌條數和長度上限；
- `--input` 模擬輸入；
- 報錯帶行號；
- 能力自檢的輸出。

**egui 界面測試**：打開常駐後，島收起時能看到插件內容。

**測試命令**：下面這條全部通過。

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File spike/cargo-serial.ps1 test --locked --lib --features "sdk-js sdk-material" --target x86_64-pc-windows-msvc sdk_spike
```
