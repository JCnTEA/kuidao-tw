- 准入規則改用 [spike/capabilities.rs](../../../spike/capabilities.rs) 裡的一張表。

金價接口首選 [xaus.com](https://xaus.com/api)，免費、無需註冊，緩存 30 秒。上架前要核實它的使用條款，並確認能否直接給出人民幣每克的價格。不能的話，就再接一個匯率來源，這正是第 2 步「多個來源」要支援的情況。備選是 GoldAPI.io，需要免費 key，額度有限，可以用第 2 步的憑據託管。

## 已定的方向

- 作者用島仔提供的組件描述界面，用少量主題令牌調樣式，島仔負責繪製。不做自由繪製，也不嵌網頁。
- 需要每秒變化的內容（跳動的數字、時鐘、倒計時）由島仔在本地逐幀計算，不讓腳本每秒運行一次。
- 不做發佈者簽名。插件照舊在插件倉審 PR，由小唐本人過目後發佈。
- 不引入付費服務或付費證書。
- 各任務負責數據約定、校驗、運行邏輯和測試。界面先用宿主現有控件畫出能用的樣子，最終的視覺設計由驗收方統一來做。

## 共同規則

- 所有回覆用中文。
- 本機 Cargo 命令一律通過 `spike/cargo-serial.ps1` 運行，它會持有互斥鎖 `Local\Daozai.Cargo`，並行度為 1。
- 每個工作樹只用自己目錄下的 `target`，不設 `CARGO_TARGET_DIR`。新工作樹第一次編譯大約需要 12 分鐘。
- 這些任務**只提交到自己的分支**：
  - 不合進 `test/acceptance` 或 `main`；
  - 不編譯 release，不替換桌面「島仔－當前測試版」；
  - 不推送到 GitHub。

  驗收、合併和出包由驗收方統一處理。
- 分支最後要合到一起，所以改動儘量放進新文件。下面這些共享位置只做增量修改：
  - 能力表 `CAPABILITIES`；
  - `spike/local.rs` 裡的 `Output` 和 `render_input`；
  - `src/plugin_status.rs` 裡的 `StatusComponent`；
  - 文檔表格；
  - 教程能力清單（`spike/plugin_guide_ui.rs` 約 225 行）。
- 插件提供的設定和選項，要在所屬設定頁的標題旁顯示「插件」小標。插件開關開啟時為紫色、關閉時為灰色，複用宿主現有組件。
- 設定頁裡的說明和關鍵提醒不要刪。狀態提示用顏色和動效表達，不加文字標籤。
- 文件多為 CRLF 換行，編輯時保持原樣。
- 每個任務都要同步更新這三處：[sdk-v1-design.md](../sdk-v1-design.md)、[sdk-v1.schema.json](../sdk-v1.schema.json)、教程能力清單。新增的能力在文檔裡標為「實驗」。
