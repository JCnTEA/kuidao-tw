# GPU 材質接口規範 v1

狀態：**定稿**，對應插件清單 `api: 1`。本文件約定的清單字段、著色器接口、控件角色和宿主行為，在 `api: 1` 內只按「穩定性約定」一節追加，不改變已有含義。第 6 階段把定稿時新增的幾項落地後，隨 `feat/gpu-material` 合進 `main`（合併前須完成文末的補測）。材質插件支援本地安裝和[本地測試集市](local-install.md#測試集市)，正式分發另行規定。

實現分支 `feat/gpu-material`，工作樹 `01-專項工程/GPU材質`。實現過程見 [gpu-material-tasks.md](gpu-material-tasks.md)。

## 目標

讓插件給島體換上實時 GPU 材質：島體背後的桌面透過材質折射、模糊或變色，控件有獨立的玻璃塊和彈性。本體只提供通用能力，不含任何具體材質的算法和參數。材質作者只交一段 WGSL 著色器和一份參數清單。

第一個材質插件是液態玻璃（作者 輕九九九，@cayww，源自 PR #235），位於 `spike/examples/liquid-glass/`，是本規範的參考實現。

## 分工

| 宿主（島仔本體）提供 | 材質插件提供 |
|---|---|
| 島體背後的桌面底片、平均亮度、帶滯回的明暗狀態 | WGSL 著色器 |
| DirectComposition 透明交換鏈，真實逐像素 alpha | 參數清單：名稱、範圍、預設值、單位、顯示精度 |
| 把著色器接進渲染通道，傳入島體輪廓、控件、指針、時間、展開速度 | 控件彈簧的剛度和阻尼 |
| 控件登記、角色編號、彈簧和按壓動畫 | 投影強度、前景樣式的選擇 |
| 島體投影、玻璃前景樣式（按鈕、卡片、文字深淺） | 作者、版本、說明 |
| 著色器檢查，出錯和超預算時停用並退回普通繪製 | |
| 根據參數清單生成設定滑塊 | |
| 靜止降頻、深休眠、抓屏節流 | |

## 運行條件

- 只在「兼容渲染（Direct3D 12）」開啟時生效。啟用材質插件時兼容渲染未開，提示開啟並重啟，期間插件處於等待狀態，基礎皮膚不變。
- 同一時間只有一個材質生效，啟用新的會停用舊的。材質疊加在使用者當前的基礎皮膚和形狀上；皮膚、形狀、停靠仍由使用者掌管。停用後外觀回到原樣。
- 只作用於主島，設定窗口和其他窗口不受影響。
- 任何一步失敗（建不起交換鏈、抓不到屏、著色器編譯失敗、連續超預算）都退回普通繪製並記入 `diagnostics/material.log`，直到使用者重新啟用，不影響島仔其他功能。
- 材質生效期間，島體窗口被排除出螢幕捕獲，截圖和錄屏裡看不到島仔。設定中「截圖和錄屏隱藏島仔」顯示為開啟並鎖定，附說明；停用後按使用者原來的選擇恢復。兩者共用宿主的 `capture::Exclusion`。

## 插件清單

```json
{
  "id": "cayww.liquid-glass",
  "name": "液態玻璃",
  "author": "輕九九九（@cayww）",
  "version": "1.0.2",
  "api": 1,
  "runtime": "material",
  "entry": "material.wgsl",
  "owner": "appearance",
  "capabilities": ["appearance.material", "settings"],
  "dataVersion": 1,
  "permissions": {"screen.backdrop": true},
  "material": {
    "controls": true,
    "spring": {"stiffness": 1.0, "damping": 0.5},
    "shadow": 1.0,
    "foreground": "glass"
  },
  "settings": [
    {"key": "refract", "label": "折射", "type": "number", "min": 0, "max": 120, "step": 1, "default": "48", "unit": "px", "precision": 0},
    {"key": "edge-opacity", "label": "白邊不透明度", "type": "number", "min": 0, "max": 1, "step": 0.01, "default": "0.9", "precision": 2}
  ]
}
```

### 字段規則

| 字段 | 規則 |
|---|---|
| `runtime` | 固定為 `"material"` |
| `owner` | 固定為 `"appearance"` |
| `capabilities` | 必須含 `"appearance.material"`；有設定項時加 `"settings"`；不允許其他能力 |
| `entry` | 包內一個 `.wgsl` 文件，不超過 64 KB |
| `permissions` | 只能是 `{"screen.backdrop": true}` |
| `material.controls` | 是否需要控件玻璃數據，布爾 |
| `material.spring` | 必填。`stiffness` 0.2 至 3.0，`damping` 0.1 至 1.0，由宿主計算彈簧後傳入著色器 |
| `material.shadow` | 可選，0 至 1.5。島體外圍投影強度，由宿主按島體輪廓繪製。不寫時沿用基礎皮膚 |
| `material.foreground` | 可選，`"skin"`（預設）或 `"glass"`，見「前景樣式」 |
| `settings` | 最多 32 項，只允許 `number` 類型，按聲明順序放進著色器的 `params` |
| `settings[].min/max/step` | 必填，`step` 大於 0 且不超過 `max - min`，`default` 在範圍內 |
| `settings[].unit` | 可選，滑塊數值後顯示的單位，最多 4 個字符，例如 `"px"`、`"%"`。只用於顯示，宿主不做換算 |
| `settings[].precision` | 可選，0 至 3，滑塊顯示的小數位數。不寫時按 `step` 的小數位數顯示 |

清單須聲明 `"cover": "cover.png"`。包內只允許 `plugin.json`、包根目錄的 `cover.png`、入口 `.wgsl` 和可選的說明文件（`.md`、`.txt`、`.rst`，或 README、LICENSE、COPYING、NOTICE、CHANGELOG）。封面須為有效 PNG，最大 256 KiB、1920×1080，建議 16:9。島仔拒絕連結、重定向路徑、腳本、可執行文件和未知清單字段。

### 權限

`screen.backdrop` 首次啟用時確認，說明文字固定為：

> 讀取島體背後一小塊螢幕畫面，只在本機用於繪製材質，不儲存、不上傳；插件本身沒有網路和文件權限。

實現上，宿主把裁剪後的像素讀回島仔進程記憶體，用於計算亮度和合成乾淨底片，再上傳為顯卡紋理。像素不寫入磁盤和日誌，插件只能在著色器裡採樣紋理。

### 前景樣式

- `"skin"`：宿主照常畫基礎皮膚的底色、按鈕和文字，材質畫在底色之上、文字和按鈕之下。
- `"glass"`：
  - 宿主不畫基礎皮膚的底色，島體底色完全由材質負責；
  - 按鈕、卡片改用宿主內置的玻璃樣式；
  - 文字和圖標隨 `motion.y` 在深色字和淺色字之間切換；
  - 顯示器拓撲剛變化、抓屏處於穩定期時，宿主臨時畫純色玻璃底。

  啟用後的外觀不受基礎皮膚影響。

## 著色器接口

宿主在插件代碼前拼接固定的前置代碼（prelude），提供輸入結構、綁定和常用函數。插件只寫片元函數：

```wgsl
fn material(i : MaterialIn) -> vec4<f32>
```

返回預乘 alpha 的顏色。頂點著色器由宿主提供，覆蓋整個抓取矩形。插件不得聲明其他綁定、`@vertex` 或 `@fragment` 入口，否則拒絕載入。

### 繪製順序和邊緣

宿主每幀按以下順序繪製，材質輸出按預乘 alpha 混合：

1. 島體投影（宿主）；
2. 基礎皮膚底色（宿主，僅 `foreground: "skin"`）；
3. 材質（插件）；
4. 按鈕、卡片、文字、圖標（宿主）。

抓取矩形比島體大，用於折射取樣。材質在 `body_sdf_exact(p) > 0` 的區域應輸出透明，可以在輪廓外 2 px 內做抗鋸齒過渡。宿主按窗口區域裁剪，不再替插件裁剪輪廓。

### Frame

```wgsl
struct Frame {
  capture : vec4<f32>,   // 抓取矩形在螢幕上的物理座標 x,y,w,h
  body    : vec4<f32>,   // 島體在抓取矩形內的 x,y,w,h（物理像素）
  shape   : vec4<f32>,   // 圓角半徑 px、展開程度 0..1、指針 x、指針 y（抓取矩形內 px）
  notch   : vec4<f32>,   // 劉海外擴寬度 px、外擴高度 px、是否劉海、保留
  env     : vec4<f32>,   // 時間 s、背景平均亮度 0..1、物理像素/邏輯點、是否透明交換鏈
  tint    : vec4<f32>,   // 封面主色 rgb、強度
  tex     : vec4<f32>,   // 底片紋理寬、高、有效區寬、高
  count   : vec4<u32>,   // 控件數量、停靠方向（0 頂部、1 左側、2 右側、3 底部）、保留、保留
  ctl_rect  : array<vec4<f32>, 16>, // 控件 x,y,w,h（抓取矩形內 px）
  ctl_shape : array<vec4<f32>, 16>, // 圓角半徑、啟用、懸停 0..1、按下 0..1
  ctl_spring: array<vec4<f32>, 16>, // 彈簧位移 x、y、縮放、控件角色（見附錄）
  params  : array<vec4<f32>, 8>,    // 插件參數，按清單 settings 順序，每 4 個一組
  motion  : vec4<f32>,   // 展開速度、宿主明暗狀態 0..1（0 深 1 淺）、平滑展開速度、保留
};
@group(0) @binding(0) var<uniform> frame : Frame;
@group(0) @binding(1) var backdrop : texture_2d<f32>;
@group(0) @binding(2) var backdrop_sampler : sampler;
```

- `Frame` 共 1040 字節，每項按 16 字節對齊。
- 標為「保留」的位置當前恆為 0，插件不得讀取，以後追加的含義不保證為 0。
- `motion.x`：展開程度每秒的變化量，收起為負，逐幀求導。
- `motion.y`：宿主明暗狀態，背景平均亮度高於 0.66 轉淺、低於 0.52 轉深，按每秒 6 倍平滑。與玻璃前景樣式的文字深淺是同一個值。
- `motion.z`：`motion.x` 經過與 PR #235 相同的逐幀衰減後的值，用於展開收尾的形變回彈。
- 控件最多 16 塊。超過時先保留附錄中標為優先的角色，再按面積從大到小補足。入選的控件按面積從大到小排列，較小的控件排在後面。

### 前置函數

```wgsl
struct MaterialIn { px : vec2<f32>, uv : vec2<f32> };   // px 為抓取矩形內的物理像素座標
fn param(i : u32) -> f32;                                 // 第 i 個插件參數
fn rr_sdf(p : vec2<f32>, b : vec2<f32>, r : f32) -> f32; // 圓角矩形距離，b 為半寬高
fn notch_sdf(p : vec2<f32>, b : vec2<f32>, r : f32, flare : f32, fh : f32) -> f32;
fn body_sdf(p : vec2<f32>) -> f32;        // 當前島體輪廓，向內收縮 3 px，留給羽化和描邊
fn body_sdf_exact(p : vec2<f32>) -> f32;  // 當前島體輪廓，不收縮，與窗口可見邊緣一致
fn sample_backdrop(px : vec2<f32>) -> vec3<f32>; // 按抓取矩形內像素座標採樣底片
```

兩個輪廓函數都已處理劉海、展開程度和四個停靠方向。距離小於 0 在島體內。

## 穩定性約定

- `api: 1` 內，`Frame` 已有字段的位置和含義、綁定編號、前置函數的簽名和含義、控件角色編號、清單已有字段的含義都不再改變。
- 新增只能是：`Frame` 末尾追加字段、使用保留位、增加前置函數、追加控件角色編號、清單增加可選字段。新增內容隨島仔版本發佈並在本文件記錄起始版本。
- 插件聲明的 `api` 大於宿主支援的版本時，拒絕安裝並提示更新島仔。
- 需要破壞性修改時升級為 `api: 2`，宿主同時保留 `api: 1` 的支援至少六個月。
- 插件 `version` 用三段語義化版本。從插件首次對外發布起，清單變化需要使用者重新安裝時至少升級第二段；發佈前的本機驗收版本不受此限，液態玻璃的 1.0.x 即屬此類。

## 性能與穩定

- 靜止時按 15 Hz 刷新，無操作 2 分鐘進入 1 Hz 深休眠，動畫和交互期間滿幀。由宿主控制，插件不可修改。
- 抓屏只讀外擴矩形，尺寸變化時不復用舊紋理。
- 著色器在宿主的錯誤範圍內編譯，失敗即停用並提示。
- 材質通道連續 120 幀 CPU 耗時超過 4 ms 自動停用。
- 啟用、停用、切換材質時釋放紋理和管線，記憶體回到啟用前水平。

## 驗收

- 關閉材質插件時，島仔各皮膚的顯示、記憶體、幀率與 `main` 一致，現有測試全部通過。
- 液態玻璃與 PR #235 預覽版在同一壁紙、頁面、參數下對比：折射、色散、白邊、投影、玻璃按鈕、文字深淺、控件透鏡、果凍彈簧和展開形變一致。
- 關閉兼容渲染、著色器寫錯、抓屏失敗時都退回普通繪製，島仔不崩潰。
- 停用插件後外觀回到啟用前的皮膚和形狀，截圖排除恢復使用者原設定。

### 合進 main 前的補測

以下三項針對會影響所有使用者的改動（兼容渲染的建窗口流程、#197 截圖排除的內部實現），未安裝材質插件時也要測。全部通過後才合進 `main`，結果記在合併說明裡。

1. **其他顯卡的兼容渲染**：在 AMD 和 NVIDIA 顯卡的機器上開啟「兼容渲染（Direct3D 12）」，不裝材質插件，檢查各皮膚的展開、收起、切頁和側邊停靠是否正常，與 `main` 的同款測試版對比無異常。
2. **截圖排除開關**：不裝材質插件時，「截圖和錄屏隱藏島仔」分別開、關並重啟，檢查開關狀態儲存、系統截圖裡島仔的顯示與開關一致；裝上材質插件後啟用、停用各一次，確認開關被鎖定和恢復原值。
3. **錄屏軟體實錄**：用 OBS 等錄屏軟體的窗口捕獲和顯示器捕獲各錄一段，確認截圖排除開啟時錄不到島仔、關閉時能錄到，材質生效期間錄不到。
