# 使用說明

## 第一次開啟

滑鼠靠近螢幕頂部的小島，會展開功能面板。左右箭頭與底部圓點切換頁面；在列表內滾輪可看更多內容。系統匣選單可開啟設定、控制開機啟動或結束程式。

首次啟動會跳出授權視窗並顯示本機機器碼，將機器碼貼進 `授權產生器.py` 取得授權碼，再執行：

```powershell
kuidao.exe --license 授權碼
```

授權檔會寫入 `%APPDATA%\Kuidao\license.key`，之後啟動不再詢問。

## 島體外觀

- **停靠位置**：頂部（橫向展開）、左側或右側（豎向膠囊），滑鼠靠近邊緣即展開。
- **大小**：80%–140%，在 **設定 → 外觀** 調整。
- **位置微調**：頂部可左右移動、側邊可上下移動。
- **皮膚**：經典黑、奶油、毛玻璃淺色、毛玻璃深色、懸浮雲。
- **吉祥物**：預設島虎（石虎），可切換柴犬；貓、哈士奇、黃金獵犬待動畫補齊。
- **OLED 像素偏移**：長時間靜止時緩慢位移，降低烙印風險，預設關閉。

## 通知與訊息

收起時亮起圖示與紅點，展開後看摘要，點擊可切到對應視窗。

- LINE、Facebook、Instagram、Threads：透過 Windows 系統通知接收，不讀取聊天內容。
- 預設不顯示通知正文；開啟預覽後仍會遮罩辨識出的驗證碼。
- 中國大陸應用（微信、QQ、飛書、釘釘、企業微信）預設隱藏，需要時可在設定中打開。

## 音樂與歌詞

播放、暫停、切歌、音量與進度都能在島上操作；展開看歌詞，收起只留一行。頂部停靠時才顯示島上單行歌詞。

- 支援 Spotify、Apple Music 等國際服務；中國大陸播放器（網易雲、QQ 音樂、酷狗、酷我、汽水、波點）預設隱藏。
- 歌詞取決於歌曲中繼資料與歌詞來源，部分歌曲可能顯示不出來。

## 日程、待辦、專注與飲水

- **日程**：月曆與當日時間線，可接 iCloud、自訂 CalDAV、Exchange ActiveSync，或匯入 `.ics`。
- **待辦**：單次提醒、每週指定日重複、每天重複。
- **專注**：番茄鐘計時，收起時仍顯示進度。
- **飲水**：自訂每日目標、單次水量、提醒間隔與時段，誤按可復原。

本機建立的日程只存在本機；遠端日曆為唯讀同步。程式結束或電腦睡眠期間不會提醒。

## 信箱與驗證碼

在島上看來信、辨識驗證碼並點一下複製。

- 支援 **Yahoo 奇摩、iCloud、Gmail、Outlook／Hotmail、自訂 IMAP**。
- 需在信箱端開啟 IMAP，並填授權碼或應用程式專用密碼。
- 驗證碼可設 30／60／300 秒後自動隱藏，涵蓋列表、內文與通知。
- 預設只在本機整理信件，不會回寫到信箱；可在設定中開啟「同步郵件操作到信箱」。

## 天氣

天氣頁顯示實況與未來七天：溫度、天氣現象、體感、濕度、風速、日出日落，以及每日高低溫與降雨機率。

- 預設依網路出口自動定位；也可在 **設定 → 天氣** 直接搜尋地名，例如「臺北市士林區」。
- 只寫區名如「士林」「內湖」也查得到，系統會對應到該區座標。
- 資料來源 Open-Meteo，免金鑰，每 15 分鐘更新；斷網時顯示上次結果並標出更新時間。

## 檔案置物與剪貼簿

- 拖入檔案臨時收集，點擊開啟或拖出到其他應用；移除紀錄不會刪除原檔。
- 剪貼簿保留最近 30 條文字，可固定常用內容；密碼管理器標記為敏感者不記錄。

## 下載與更新

- 安裝版：`GuiDao-DynamicIsland-Setup-v版本-x64.exe`，可選安裝路徑、桌面捷徑、開機自啟。
- 免安裝版：解壓後執行 `kuidao.exe`，資料仍寫在 `%APPDATA%\Kuidao`。
- 更新：設定 → 關於 → 檢查更新；升級保留設定與資料，卸載同樣保留。

## 常見問題

**Windows 顯示「已保護您的電腦」**

程式未做商業簽章，屬正常提示。執行倉庫內的 `解除封鎖.bat` 清除下載標記，或右鍵內容 → 解除封鎖。

**顯示卡或驅動較舊，開起來黑畫面**

程式預設 OpenGL，失敗時自動改試 Direct3D 12；仍不正常可在設定關閉硬體加速。

**自己編譯**

```powershell
cargo build --locked --release --bin kuidao
```

或雙擊 `一鍵編譯免安裝版.bat`。
