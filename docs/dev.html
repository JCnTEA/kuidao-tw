鬼島 開發版 專用下載

開發版是主線每次改動就發佈的版本：功能先上、修正快、變動多。這一頁的下載網址固定不變， 檔案本身由每次開發版建置自動換新，所以把這個網址存成書籤就能一直拿到最新開發版安裝檔。

三件最重要的事，先看這段再安裝。

固定下載網址

這一頁的連結永遠指向最新開發版安裝檔，不用每次去找新的 Release，也不用記版本號。

自己的安裝資料夾

開發版安裝到使用者自己的 %LOCALAPPDATA%\KuidaoDev，正式版在 Program Files，兩套可以同時開。

啟動器自動更新

安裝包裡只有一個極小的開發版啟動器。每次開啟先確認最新開發版，版本不同就把程式與素材整包換新再開啟。

安裝流程

三步結束，第一次開啟會需要一點下載時間。

1
執行安裝檔開啟 KuidaoDev-Setup-TW-x64.exe，不需要管理員權限，桌面與開始選單會出現「鬼島 Kuidao 開發版」捷徑。若正式版正在執行，安裝器會先強制關閉正式版的工作（只結束程序，不會移除正式版的檔案與設定）。
2
完成頁按下載並開啟安裝完成後啟動器會抓最新開發版（程式檔＋assets 素材），下載完自動開啟鬼島。
3
之後照平常開就好之後每次點捷徑，啟動器會先比對版本；有新版就靜默更新，沒有新版直接開啟。
先說清楚：開發版是測試性質。功能會先上，改動密集，偶爾會有沒預期到的狀況。 正式版維持穩定、只在確認沒問題後才跟進。開發版有問題請直接回報，會以開發版為主線修。 安裝檔目前沒有程式碼簽章，Windows 可能會跳 SmartScreen 提示，選擇「仍要執行」即可。

移除方式

開發版可以單獨移除，不會動到正式版。

從「設定 → 應用程式」找到「鬼島 Kuidao 開發版」解除安裝，或直接執行安裝資料夾裡的 Uninstall.exe。 設定、歌詞庫與診斷紀錄放在 %APPDATA%\Kuidao，會保留給下次重新安裝使用。
