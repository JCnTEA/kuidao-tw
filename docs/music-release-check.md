## 2. 不再接觸其他軟件

1. 打開企業微信、瀏覽器等軟件，再播放網易雲或酷狗。
2. 用 Process Explorer（Sysinternals）選中鬼島進程，打開下方 Handles 視圖，篩選類型為 Process 的句柄。
3. 預期：帶內存讀取權限的句柄只指向網易雲 / 酷狗；企業微信等其他進程最多隻出現“有限查詢”權限的短暫句柄。

結果：☐

## 3. 歌詞重試

1. 播放一首確定查不到歌詞的歌，等待顯示「未找到匹配歌詞」。
2. 點擊「點擊重試」。
3. 打開 `%APPDATA%\kuidao\diagnostics\lyrics.log`，最新一行應出現「手動重試:跳過無歌詞記錄」，並有實際聯網查詢步驟。
4. 不點重試、自然切回這首歌時，應仍命中「近期已確認無同步歌詞」，不重複聯網。

結果：☐
