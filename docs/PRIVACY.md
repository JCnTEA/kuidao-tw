# 隱私與安全

## 本機數據

鬼島預設在 `%APPDATA%\kuidao` 儲存使用者設定、待辦、本機日程及提醒設定、飲水記錄、置物文件路徑、連接元數據以及忽略的郵件日程標識。環境變量 `kuidao_DATA_DIR` 可指定另一目錄。置物架儲存原文件路徑，不復制文件正文。本機日程不上傳到工作日曆。

信箱和日曆密碼通過 Windows 憑據管理器儲存；獨立 Gemini 會話與豆包網頁會話使用當前 Windows 使用者的 DPAPI 加密。連接元數據中可能包含信箱地址、帳號名稱和本機登錄文件路徑，因此整個數據目錄都不適合公開上傳。

程序讀取收件箱內的郵件以展示正文、提取驗證碼與日曆邀請。當前郵件記錄儲存在記憶體中；不要將運行中的記憶體轉儲公開分享。

## 網路訪問

音樂兼容功能會只讀訪問汽水音樂、酷狗音樂的本機歌詞緩存，以及網易雲音樂的本機播放日誌和播放隊列；酷狗配置僅用於提取歌詞目錄。只保留歌詞、歌曲 ID、歌名、歌手、專輯、公開封面地址、播放狀態和時間軸，本地隊列缺少網易雲曲目訊息時按歌曲 ID 向網易雲查詢；系統和本機均未提供封面時，會用歌名和歌手向網易雲搜索並下載匹配的專輯縮略圖。日誌正文、音訊簽名連結等內容不會儲存或上傳。網易雲原生播放事件不依賴 SMTC 或固定記憶體地址；必要時仍可對已匹配的網易雲、酷狗版本只讀獲取播放進度。不會修改播放器、讀取音訊或提取登錄訊息。啟動或運行異常的診斷日誌儲存在數據目錄的 `diagnostics/last-error.log`，不會自動上傳。

啟用對應功能後，程序會聯繫信箱 IMAP 服務、工作日曆 CalDAV / Exchange ActiveSync 服務、AI 服務額度接口以及歌詞服務。連接方式和伺服器見源碼中的 `mail.rs`、`calendar.rs`、`quota.rs`、`lyrics.rs` 及對應 provider 模塊。

音樂識別不完整時，本地診斷日誌可能包含播放器名稱、歌名、歌手和歌曲 ID。影片或類型未識別的媒體只記錄來源與缺少的訊息。導出的診斷包由使用者自行選擇是否分享。

Windows 下的工作日曆連接使用系統 TLS 和證書信任庫，保留證書有效期及伺服器名稱校驗。自簽證書或私有 CA 需要先由使用者或管理員加入 Windows 信任庫。日曆診斷日誌只記錄服務類型、同步範圍、錯誤分類和數量統計，不記錄伺服器地址、憑據或日程正文。

開啟天氣模塊後，程序會訪問 Open-Meteo 獲取天氣；手動指定城市時向其地理編碼服務發送城市名，自動定位時優先通過 `https://ipwho.is/` 獲取網路出口的大致城市與座標，失敗時嘗試 `https://free.freeipapi.com/api/v1/json`，再用座標查詢天氣。請求優先直連，必要時可回退到使用者已配置的系統或環境變量代理，兩個定位服務的直連嘗試先於代理嘗試。自動刷新間隔為 15 分鐘，關閉天氣模塊後不再發起新一輪查詢，在途結果不更新界面或緩存。天氣查詢不讀取帳號、信箱或日程數據。各城市最近一次天氣快照儲存在數據目錄的 `weather-cities.json`，供斷網時查看；系統 TUN/VPN、代理和共享網路出口仍可能影響定位位置。

切換為和風天氣後，城市搜索、實況和七日預報只訪問使用者提供的官方 `qweatherapi.com` 專屬域名，使用 HTTPS 和 `X-QW-Api-Key` 請求頭，不跟隨重定向。Key 僅儲存在 Windows 憑據管理器，不寫入普通設定、日誌、診斷包或天氣緩存。和風城市需重新手動選擇，不復用 Open-Meteo 的座標或自動定位；預設來源及其已儲存城市保持不變。

和風實況約每 60 分鐘、預報約每 6 小時刷新，僅調度當前城市；天氣緩存與請求計數分別儲存在 `qweather-cache.json` 和 `qweather-usage.json`，來源及使用者選擇儲存在 `weather-provider.json`。本機每自然月最多 5,000 次出站嘗試，搜索、連接測試、手動刷新及失敗嘗試統一先記帳再發送；計數無法儲存時停止請求。關閉天氣頁面模塊後停止和風新請求並丟棄在途結果，狀態組件開關只控制常駐顯示。和風帳號的免費額度由同一帳號的其他設備和項目共享，鬼島無法限制其他應用的用量。

天氣連接診斷儲存在 `diagnostics/weather-network.log`，只記錄請求階段、服務域名、直連或代理、耗時和錯誤類別，不記錄 IP、經緯度、城市查詢參數、代理地址或憑據。每份日誌最多 256KB，輪轉保留上一份，不會自動上傳。

島仔正式版僅在啟動時自動訪問 GitHub 的公開發布接口。通常在上次檢查成功滿 24 小時或失敗滿 1 小時後，於下次啟動時再次檢查。啟動階段結束後收到的新版訊息可在「設定 → 關於」查看。也可以手動點擊「檢查更新」。請求頭包含島仔版本號，不發送本地設定、信箱或日程數據。下次可檢查時間和已提醒的版本號儲存在本機。選擇「下載並安裝」會從 GitHub 下載公開安裝包至 `%LOCALAPPDATA%\Daozai\Updates`，核對大小及 SHA-256 後替換程序並重啟；「瀏覽器下載」通過預設瀏覽器打開發布頁。

打開「設定 → 關於」時，程序會從 GitHub Pages 刷新公開的感謝牆名單和圖片，並在本機緩存。請求包含島仔版本號。

打開插件集市時，程序會從 Gitee 讀取目錄、封面和作者頭像，並向集市統計服務查詢下載數和收藏數。下載或收藏後，統計服務收到隨機生成的本機安裝標識及該插件的操作記錄，不包含本地設定或帳號訊息。本地導入不計入集市下載。

程序不使用統一的鬼島雲端帳號，也沒有項目自建的郵件或日程上傳後台。第三方服務自身的數據處理政策仍然適用。

## 登錄憑據

中轉站的自定義查詢腳本與其中的憑據由當前 Windows 使用者的 DPAPI 加密儲存。腳本只能請求與所填站點協議、主機和端口相同的接口。站點使用 HTTPS，本機的 `localhost`、`127.0.0.1` 和 `[::1]` 也支援 HTTP 直連。本機 HTTP 查詢會繞過代理，所有腳本查詢均禁用重定向。普通 API Key 與 New API 使用者 Token 仍儲存在 Windows 憑據管理器中。

新安裝時，AI 額度從空帳號列表開始。可以在設定中選擇「識別本機帳號」或連接指定客戶端。已有帳號按額度功能的設定刷新。本機登錄文件只讀使用，不修改原客戶端配置或替它刷新登錄。獨立連接的憑據由島仔自己的安全存儲管理。不要把 Cookie、授權碼、登錄 JSON、憑據文件、真實郵件或私人日程提交到 GitHub。

GLM Coding Plan 使用你在島仔裡填寫的套餐 API Key，儲存在 Windows 憑據管理器。舊的 ZCode 本機登錄連接需在 AI 額度設定中重新連接。
