- 插件集市上線，首批 8 款可在「設置 → 插件」安裝。
- 新增系統性能和無線設備頁，性能指標、網速和設備電量可在島上常駐。
- 支持底部停靠、跨屏拖動，以及在兼容的截圖和錄屏工具中隱藏島仔。

### 新增

- 首批插件包括液態玻璃、我的日子、現貨金價、實時工資、便籤本、世界時鐘、頁面快捷切換和無線設備兼容包。液態玻璃是輕九九九（@cayww）的社區插件。
- 日程新增按日期瀏覽、農曆常駐和時間選擇器。郵箱可只提醒驗證碼，Gmail 收信支持 Windows 手動代理。
- AI 額度加入 Antigravity，「關於」新增感謝牆。

### 優化

- 集市支持按下載量或最新更新排序、收藏和作者頭像。獨立功能插件啟用後才出現在側欄和島上，更新時保留設置和數據。
- 兼容渲染下展開、收起和翻頁更順滑，切頁時頂欄和箭頭更穩定，置物架和剪貼板可保持展開。
- 切歌、暫停和拖進度同步更快，改善酷狗和網易雲部分版本的進度適配。
- 自動更新提示集中在啟動時，在線升級留出更充足的準備時間，診斷可直接生成 ZIP。

### 修復

- 修復部分釘釘、飛書提醒點不開或打開後仍保留，以及頂部任務欄擋住通知點擊。
- 修復波點歌曲顯示成編號，以及藍牙設備切換電量來源後讀數或提醒異常。
- 修復側邊控件裁切、兼容渲染首幀閃黑、毛玻璃開關失效，以及透明邊緣擋住點擊。
- 修復窄窗口的集市分類遮擋、島上組件增減時偏移，以及喝水頁切換圖表卡頓。
- 修復 CalDAV 連上後無法保存、Kimi Code 重新登錄後額度未恢復，以及中文輸入法選詞時誤提交。

### 升級與下載

點「下載並安裝」即可升級，設置和記錄會保留。也可在「設置 → 關於」手動檢查更新。首次安裝選 EXE，免安裝選 ZIP。
