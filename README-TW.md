# 鬼島 · Kuidao（台灣繁體版）

**一座小島，裝下桌面日常。** Windows 桌面夥伴，把訊息、音樂、行程、天氣和 AI 額度放到手邊。

本專案是 [Renly1994/xiaotang-daozai](https://github.com/Renly1994/xiaotang-daozai)（原作者：小唐，MIT 授權）的**台灣在地化版本**，只調整繁體中文介面與台灣使用習慣，不改動功能邏輯。

---

## 這個版本改了什麼

### 1. 介面全面繁體中文（台灣用語）
- 7,700 餘條介面字串由簡體轉為繁體，並套用台灣慣用詞：
  設定／檔案／資料夾／網路／螢幕／滑鼠／儲存／搜尋／支援／列印／捷徑／系統匣／行事曆／剪貼簿／記憶體／軟體／影片／音訊／資訊／預設／登入／帳號／游標／桌布。
- 專有名詞維持原樣：微信、QQ、飛書、釘釘、企業微信、網易雲音樂、QQ 音樂、酷狗、汽水音樂、DeepSeek 等，避免使用者對不上原本的服務。

### 2. 字型改用台灣字形
- 介面字型優先載入 **微軟正黑體（Microsoft JhengHei）**，繁體字以台灣寫法呈現（「為」「裡」「著」等字形正確）。
- 系統沒有正黑體時，才依序退回微軟雅黑、Noto Sans TC／SC、Noto Sans CJK。

### 3. 台灣使用習慣
- 時鐘預設 **12 小時制**（上午／下午），可在設定改回 24 小時制。
- 溫度為攝氏、日期為西元、時區跟隨系統（Asia/Taipei）。
- 安裝程式、版本資源、解除安裝頁面全部改為**台灣繁體中文**（NSIS 語言 1028／版本資源 0x0404）。

### 4. 不讓繁中介面弄壞功能
原本程式有幾處是「用簡體字串去比對外部資料」，介面轉繁中後若跟著改，會抓不到東西。這版已逐處補回簡體相容：
- 汽水音樂：媒體來源同時接受「汽水音樂」與「汽水音乐」。
- 飛書：主視窗標題同時接受「飛書」「飞书」「Feishu」「Lark」。
- 藍牙、電源、網路、音量、輸入語言等提示：產生端與判斷端一起在地化，圖示與顏色照常。
- 郵件驗證碼關鍵字、行事曆欄位：原始碼本來就有繁簡雙寫，未動。

## 台灣使用者可直接用的功能

| 需求 | 支援情況 |
|---|---|
| 音樂與歌詞 | Windows 媒體工作階段：Spotify、Apple Music（iTunes）、YouTube（瀏覽器）、KKBOX（有媒體工作階段時）、網易雲、QQ 音樂、酷狗、汽水音樂 |
| 郵件與驗證碼 | Gmail、iCloud、QQ、163／126、騰訊企業信箱、自訂 IMAP（驗證碼可點一下複製） |
| 行事曆 | Google（iCal／CalDAV）、iCloud CalDAV、Exchange、飛書、釘釘、企業微信、`.ics` 匯入 |
| 天氣 | Open-Meteo 免 Key（可填「臺北市」「Taipei」），或自備和風天氣 Key |
| AI 額度 | Codex、Claude、Kimi、Grok、Gemini、DeepSeek、Kiro、WorkBuddy 等 |
| 其他 | 剪貼簿 30 筆、檔案置物架、待辦、番茄鐘、喝水提醒、藍牙電量、通知 |

## 安裝

1. 到 Releases 下載 `Kuidao-Setup-v0.6.66-x64.exe`（安裝版，可選路徑、桌面捷徑、開機自啟）。
2. 或下載 `Kuidao-v0.6.66-windows-x64.zip` 免安裝版，解壓後執行 `daozai.exe`。
3. 首次啟動若出現 Windows SmartScreen 藍色警告（安裝檔沒有市集簽章），按「更多資訊 → 仍要執行」。

需求：Windows 10／11 64 位元。資料只存在本機使用者目錄，不上傳。

## 已知限制（不會假裝支援）

- **LINE 桌面版尚未納入未讀提醒**：目前聊天提醒只涵蓋微信、QQ、飛書、釘釘、企業微信。LINE 在 Windows 不會像微信那樣以工作列閃動提供穩定訊號，硬做容易誤報，因此暫不加入。
- 微信／QQ 提醒預設關閉（台灣使用者較少用，可在「設定 → 通知」自行開啟）。
- 和風天氣要自備 API Host 與 Key；不設定就用免費的 Open-Meteo。
- 介面為繁體中文，但服務本身回傳的內容（例如和風天氣的天氣描述、對岸服務的通知）可能是簡體，屬外部資料，不影響操作。

## 從原始碼建置（Windows）

```powershell
# 需要 Rust stable + Visual Studio Build Tools（C++ 桌面開發）
cargo build --release
# 產物：target\x86_64-pc-windows-msvc\release\daozai.exe

# 打包安裝檔（需 NSIS，腳本會自動下載）
powershell -File scripts\package.ps1
```

Linux 上僅能編譯錄影工具（`--features record`），正式執行檔請在 Windows 建置。
